# Code of conduct

BuildSweep is a small project. The expectation is that discussion stays useful and respectful.

## Participation

- Critique the change, the path rule, or the test. Leave personal attacks out of issues, pull requests, and email.
- Stay on the topic of the app: Xcode and allowlisted AI-tool storage, and the safety rules around cleanup.
- Give enough detail to reproduce a bug, and enough context for a feature that someone else can evaluate it.
- Maintainers may edit labels, ask for a smaller pull request, or close a report that does not include the information the template asks for.

## Reports and proposals

- Bugs and feature ideas use the GitHub issue templates described in `CONTRIBUTING.md`.
- Security reports stay private. Use `SECURITY.md`.
- Pull requests should follow an issue when the change affects cleanup rules or adds a new kind of folder.

## Enforcement

Mail `support@ayushdev.com` if someone is harassing you or disrupting the project. The maintainer will remove comments or block further participation when that is warranted. Reports about conduct are kept private aside from whatever is required to act on them.
